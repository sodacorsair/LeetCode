You are given two positive integers n and k.

A valid sequence is a sequence of k positive integers such that:

The sum of all integers in the sequence is equal to n.
The product of all integers in the sequence is even.
Return the number of valid sequences. Since the answer may be very large, return it modulo 109​​​​​​​ + 7.

Two sequences are considered different if they differ at any index. For example, [1, 1, 2] and [1, 2, 1] are considered different sequences.

 

Example 1:

Input: n = 5, k = 3

Output: 3

Explanation:

The sequences of length k = 3 whose sum is 5 are:

Sequence	Product	Parity
[1, 1, 3]	1 * 1 * 3 = 3	Odd
[1, 2, 2]	1 * 2 * 2 = 4	Even
[2, 1, 2]	2 * 1 * 2 = 4	Even
[2, 2, 1]	2 * 2 * 1 = 4	Even
[1, 3, 1]	1 * 3 * 1 = 3	Odd
[3, 1, 1]	3 * 1 * 1 = 3	Odd
There are 3 sequences with an even product, thus the answer is 3.

Example 2:

Input: n = 3, k = 2

Output: 2

Explanation:

The sequences of length k = 2 whose sum is 3 are:

Sequence	Product	Parity
[1, 2]	1 * 2 = 2	Even
[2, 1]	2 * 1 = 2	Even
There are 2 sequences with an even product, thus the answer is 2.

Example 3:

Input: n = 5, k = 5

Output: 0

Explanation:

The only possible sequence of length k = 5 whose sum is 5 is [1, 1, 1, 1, 1], which has an odd product. Thus, the answer is 0.

 

Constraints:

1 <= n <= 5 * 105
1 <= k <= n

Thought:

Counint sequences with even product directly is comlicated because it requires at least one even number. Instead, we can use complementary counting.

1. Total Sequences. Using the "stars and bars" therorem, the number of sequences with length $k$ that sum to $n$ is $\binom{n-1}{k-1}$.
2. Invalid sequences with odd product. A sequence has odd product if and only if all of its elements are odd. Let each element be
$2y_i + 1$ (where $y_i \ge 0$), the equation $\sum_{i=1}^k (2y_i + 1) = n$ simplifies to $\sum_{i=1}^k y_i = \frac{n-k}{2}$.
  * If $n - k$ is odd, no such sequence exists.
  * Otherwise, finding non-negative solutions is anotherx "stars and bars" problem, yielding $\binom{\frac{n-k}{2} + k - 1}{k - 1}$.

 Finally, the answer is the total sequences minus invalid sequences. We can compute these combinations in $O(N)$ time by precomputing
 factorials and their modular inverses using Fermat's Little Theorem.

 Solution:

 ```
class Solution {
    public int countValidSequences(int n, int k) {
        long mod = (long)(1e9 + 7);
        long[] fact = new long[n + 1], invFact = new long[n + 1];
        
        fact[0] = 1;
        for (int i = 1; i <= n; i++) fact[i] = fact[i - 1] * i % mod;

        invFact[0] = 1;
        invFact[n] = pow(fact[n], mod - 2, mod);
        for (int i = n - 1; i > 0; i--) invFact[i] = invFact[i + 1] * (i + 1) % mod;

        long total = comb(n - 1, k - 1, fact, invFact, mod);
        long totalOdd = 0;
        if ((n - k) % 2 == 0) {
            int m = (n - k) / 2;
            totalOdd = comb(m + k - 1, k - 1, fact, invFact, mod);
        }

        long totalEven = (total - totalOdd + mod) % mod;
        return (int)totalEven;
    }

    private long comb(int m, int n, long[] fact, long[] invFact, long mod) {
        return fact[m] * invFact[n] % mod * invFact[m - n] % mod;
    }

    private long pow(long base, long exp, long mod) {
        long res = 1L;
        base %= mod;

        while (exp > 0) {
            if ((exp & 1) > 0) res = res * base % mod;
            base = base * base % mod;
            exp >>= 1;
        }

        return res;
    }
}
```
