You are given an integer array nums of length n.

Alice and Bob are playing a game. Alice chooses:

An integer k such that k > 1.
Two integers l and r such that 0 <= l <= r < n.
Initially, both Alice's and Bob's scores are 0.

For each index i in the range [l, r] (inclusive):

If nums[i] is divisible by k, Alice's score increases by nums[i].
Otherwise, Bob's score increases by nums[i].
The score difference is Alice's score minus Bob's score.

Alice wants to maximize the score difference. If there are multiple values of k that achieve the maximum score difference, she chooses the smallest such k.

Return the product of the maximum score difference and the chosen value of k. Since the result can be large, return it modulo 109 + 7.

 

Example 1:

Input: nums = [1,4,6,8]

Output: 36

Explanation:

Alice can choose k = 2, l = 1, and r = 3.
All values in nums[1..3] are divisible by 2, so Alice's score is 4 + 6 + 8 = 18, while Bob's score is 0.
The score difference is 18, which is the maximum possible. Among all values of k that achieve this score difference, the smallest is 2.
Therefore, the answer is 18 * 2 = 36.

Example 2:

Input: nums = [2,1,2]

Output: 6

Explanation:

Alice can choose k = 2, l = 0, and r = 2.
The values nums[0] and nums[2] are divisible by 2, so Alice's score is 2 + 2 = 4. The value nums[1] is not divisible by 2, so Bob's score is 1.
The score difference is 4 - 1 = 3, which is the maximum possible. Among all values of k that achieve this score difference, the smallest is 2.
Therefore, the answer is 3 * 2 = 6.

Example 3:

Input: nums = [1]

Output: 1000000005

Explanation:

Alice must choose some k > 1. The smallest possible choice is k = 2.
Since nums[0] is not divisible by 2, Alice's score is 0, while Bob's score is 1.
The score difference is -1, which is the maximum possible.
Therefore, the answer is -1 * 2 = -2. Modulo 109 + 7, this equals 1000000005.
 

Constraints:

1 <= nums.length <= 1000
1 <= nums[i] <= 106


### 🌟 Core Insight: Reducing the Problem to Kadane's + Prime Factors

At first glance, this looks like a terrifying brute-force problem where you have to test infinite values of `k` and all possible subarrays $O(N^2)$. However, by applying two mathematical reductions, we can crush this problem into a blazing-fast $O(N \cdot \text{distinct\_primes})$ solution.

#### 1. The Subarray Reduction (Kadane's Algorithm)
For any fixed integer `k`, we can map the original array `nums` into a new "score array":
*   If `nums[i] % k == 0`, Alice gets the points: `val = nums[i]`
*   If `nums[i] % k != 0`, Bob gets the points (meaning Alice loses them): `val = -nums[i]`

Now, Alice needs to pick a range `[l, r]` to maximize the sum of this mapped array. This is the exact definition of the **Maximum Subarray Sum** problem! We can solve this for any fixed `k` in strict $O(N)$ time using **Kadane's Algorithm**.

#### 2. The Search Space Reduction (Why `k` MUST be a Prime)
Do we need to check every possible integer for `k`? **Absolutely not.**

*   **Rule 1: `k` must be a factor of some element in `nums`.** If `k` doesn't divide *any* number in the array, every element becomes negative (`-nums[i]`), resulting in a negative maximum subarray sum.
*   **Rule 2: `k` must be a Prime Number.** Suppose you consider a composite number like `k = 4`. Any number divisible by 4 is mathematically guaranteed to be divisible by 2. Therefore, if we choose `k = 2` instead, every positive contribution we had at `k = 4` remains positive, and *additional* numbers might also turn positive. 
    Thus, the Maximum Subarray Sum for a prime factor is **always $\ge$** the sum for its composite multiples. 
    Furthermore, the problem asks us to return the *smallest* `k` in case of a tie. Since 2 < 4, the prime always wins! 

**Conclusion:** We only need to extract all the **unique prime factors** from the numbers present in `nums` and test them using Kadane's algorithm.

---

### 🛠️ Algorithm Steps

1.  **Extract Unique Primes:** Iterate through `nums`. For each number, find its prime factors (using standard $O(\sqrt{X})$ factorization) and store them in a `HashSet`.
2.  **The "All Ones" Edge Case:** If the array consists entirely of `1`s, our prime set will be empty (since 1 has no prime factors). In this scenario, any `k > 1` will turn all elements to `-1`. The max subarray sum is `-1`. Since we want the smallest valid `k`, Alice is forced to choose `k = 2`. The answer is simply `-1 * 2 = -2`, which we then modulo appropriately.
3.  **Simulate with Kadane's:** Loop through our set of unique primes. For each prime `p`, run Kadane's algorithm to find the maximum score difference. 
4.  **Track the Best `k`:** Keep track of the `maxDiff`. If we find a strictly greater sum, update `maxDiff` and `bestK`. If we find a tie (`currMaxSum == maxDiff`), update `bestK` only if the current prime `p` is smaller.
5.  **Calculate Result:** Return `(maxDiff * bestK) % (10^9 + 7)`. Be careful with negative values during the modulo operation in languages like Java/C++.

---

### ⏱️ Complexity Analysis

*   **Time Complexity:** 
    *   **Prime Factorization:** For each number up to $10^6$, factorization takes at most $O(\sqrt{10^6}) = 1000$ operations. For $N=1000$, this takes $\le 10^6$ operations.
    *   **Kadane's Loop:** The number of *unique* prime factors across the entire array is quite small (at most a few hundred). For each prime, Kadane's takes $O(N)$. 
    *   **Overall Time Complexity:** $O(N \sqrt{\max(nums)} + P \cdot N)$ where $P$ is the number of unique primes. This easily executes in a few milliseconds.
*   **Space Complexity:** $O(P)$ to store the unique primes in the `HashSet`, which uses negligible memory.

```
class Solution {
    public int divisibleGame(int[] nums) {
        Set<Integer> primes = new HashSet();
        for (int a : nums) {
            int t = a;
            
            for (int i = 2; i * i <= t; i++)
                if (t % i == 0) {
                    primes.add(i);
                    t /= i;
                }

            if (t > 1) primes.add(t);
        }

        long mod = (long)(1e9 + 7);
        if (primes.isEmpty()) {
            long ans = -1L * 2L;
            ans = (ans % mod + mod) % mod;
            return (int)ans;
        }

        long maxDiff = Long.MIN_VALUE;
        long bestK = Long.MAX_VALUE;

        for (int p : primes) {
            long curMaxSum = Long.MIN_VALUE, curSum = 0;

            for (int a : nums) {
                int val = a % p == 0 ? a : -a;
                curSum = Math.max(curSum + val, val);
                curMaxSum = Math.max(curMaxSum, curSum);
            }

            if (curMaxSum > maxDiff || curMaxSum == maxDiff && bestK > p) {
                maxDiff = curMaxSum;
                bestK = p;
            }
        }

        long ans = (maxDiff * bestK % mod + mod) % mod;
        return (int) ans;
    }
}
```
