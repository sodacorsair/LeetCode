You are given an integer n representing the number of nodes in a graph, labeled from 0 to n - 1.

You are also given an integer array nums of length n and an integer maxDiff.

An undirected edge exists between nodes i and j if the absolute difference between nums[i] and nums[j] is at most maxDiff (i.e., |nums[i] - nums[j]| <= maxDiff).

You are also given a 2D integer array queries. For each queries[i] = [ui, vi], find the minimum distance between nodes ui and vi. If no path exists between the two nodes, return -1 for that query.

Return an array answer, where answer[i] is the result of the ith query.

Note: The edges between the nodes are unweighted.

 

Example 1:

Input: n = 5, nums = [1,8,3,4,2], maxDiff = 3, queries = [[0,3],[2,4]]

Output: [1,1]

Query	Shortest Path	Minimum Distance
[0, 3]	0 → 3	1
[2, 4]	2 → 4	1
Thus, the output is [1, 1].

Example 3:

Input: n = 3, nums = [3,6,1], maxDiff = 1, queries = [[0,0],[0,1],[1,2]]

Output: [0,-1,-1]

Explanation:

There are no edges between any two nodes because:

Nodes 0 and 1: |nums[0] - nums[1]| = |3 - 6| = 3 > 1
Nodes 0 and 2: |nums[0] - nums[2]| = |3 - 1| = 2 > 1
Nodes 1 and 2: |nums[1] - nums[2]| = |6 - 1| = 5 > 1
Thus, no node can reach any other node, and the output is [0, -1, -1].

 

Constraints:

1 <= n == nums.length <= 105
0 <= nums[i] <= 105
0 <= maxDiff <= 105
1 <= queries.length <= 105
queries[i] == [ui, vi]
0 <= ui, vi < n

Thought:

The core idea is to sort the unique elements of the original array, and maintain a two dimensional sparse table `up` for each element in the array, 
where `up[i][p]` indicates the furthest index that could be reached by the element `i` in exact $2^p$ optimal jumps. 
With this precomputation, we can use binary lifting method to answer each minimum distance query in $O(\log N)$ time complexity.

Solution:

```
class Solution {
    public int[] pathExistenceQueries(int n, int[] nums, int maxDiff, int[][] queries) {
        boolean[] buckets = new boolean[100001];
        int max = 0;
        for (int a : nums) {
            buckets[a] = true;
            max = Math.max(a, max);
        }

        int m = 0;
        for (boolean a : buckets)
            if (a) m++;

        int[] mapping = new int[max + 1], arr = new int[m];
        for (int i = 0, id = 0; i <= max; i++)
            if (buckets[i]) {
                arr[id] = i;
                mapping[i] = id++;
            }

        int[] next = new int[m + 1];
        for (int i = 0, j = 0; i < m; i++) {
            while (j < m && arr[i] + maxDiff >= arr[j])
                j++;
            next[i] = j - 1;
        }

        int log = (int)(Math.log(m) / Math.log(2)) + 2;
        int[][] up = new int[m][log];

        for (int i = 0; i < m; i++) up[i][0] = next[i];

        for (int i = 1; i < log; i++)
            for (int j = 0; j < m; j++)
                up[j][i] = up[up[j][i - 1]][i - 1];

        int k = queries.length;
        int[] res = new int[k];

        for (int i = 0; i < k; i++) {
            int[] q = queries[i];

            if (q[0] == q[1]) continue;

            int u = nums[q[0]], v = nums[q[1]];
            if (u == v) {
                res[i] = 1;
                continue;
            }

            int minval = Math.min(u, v), maxval = Math.max(u, v);
            int minid = mapping[minval], maxid = mapping[maxval];
            if (up[minid][log - 1] < maxid) {
                res[i] = -1;
                continue;
            }

            int jumps = 0;
            for (int p = log - 1; p >= 0; p--)
                if (up[minid][p] < maxid) {
                    minid = up[minid][p];
                    jumps += 1 << p;
                }

            res[i] = jumps + 1;
        }

        return res;
    }
}
```
