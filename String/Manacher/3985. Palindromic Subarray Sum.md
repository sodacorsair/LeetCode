You are given an integer array nums.

Return the maximum possible sum of a subarray of nums that is a palindrome.

 

Example 1:

Input: nums = [10,10]

Output: 20

Explanation:

The whole array [10,10] is a palindrome. Therefore, the maximum sum is 10 + 10 = 20.

Example 2:

Input: nums = [1,2,3,2,1,5,6]

Output: 9

Explanation:

The contiguous subarray [1,2,3,2,1] is a palindrome. Its sum is 1 + 2 + 3 + 2 + 1 = 9 and it is the maximum sum.

Example 3:

Input: nums = [7,1,2,1,7,3,4,3,4]

Output: 18

Explanation:

The contiguous subarray [7,1,2,1,7] is a palindrome. Its sum is 7 + 1 + 2 + 1 + 7 = 18 and it is the maximum sum.

Example 4:

Input: nums = [1,2,3,4,5]

Output: 5

Explanation:

No subarray with length greater than 1 is a palindrome. The largest element in the array is 5. Therefore, the answer is 5.

Example 5:

Input: nums = [1000]

Output: 1000

Explanation:

The subarray with only one element is a palindrome. Therefore, the answer is 1000.

 

Constraints:

1 <= nums.length <= 105
1 <= nums[i] <= 10​​​​​​​9




# 🌟 O(N) Manacher's Algorithm + Prefix Sum | 降维打击

### 💡 Core Insight: Why Manacher's Algorithm?
At first glance, finding the maximum subarray sum of a palindrome seems to require $O(N^2)$ to check all possible palindromic centers and calculate their sums. However, the constraints give us a massive hint: **$1 \le nums[i] \le 10^9$**.

Since all elements are strictly positive, **expanding a palindrome will ALWAYS increase its sum.** 
Therefore, the maximum palindromic subarray sum must belong to a **Maximal Palindrome** — a palindrome that has expanded as far as possible until the characters mismatch or it hits the array boundaries. 

What algorithm finds all maximal palindromes in $O(N)$ time? **Manacher's Algorithm**.

### 🛠️ Algorithm Steps

**1. Prefix Sum Array ($O(1)$ Range Sum):**
Since elements can be up to $10^9$ and the array length is $10^5$, the maximum sum can reach $10^{14}$. We must use a `long` array to compute prefix sums. This allows us to calculate the sum of any palindrome in $O(1)$ time once Manacher's algorithm gives us its start index and length.

**2. Array Transformation (Dummy Delimiters):**
To handle both odd and even-length palindromes uniformly, we insert delimiters. Since the original array contains only positive integers, we can safely use **negative numbers** as our dummy delimiters.
*   Start boundary: `-2`
*   In-between separators: `-1`
*   End boundary: `-3`
*   Example: `[10, 10]` -> `[-2, -1, 10, -1, 10, -1, -3]`

**3. Manacher's Core Expansion:**
We maintain the center `C` and right boundary `R` of the rightmost palindrome discovered so far. For each index `i`, we use the mirrored value `P[mirror]` to skip redundant comparisons.

**4. Index Mapping & Sum Evaluation:**
Once we find the maximal palindrome radius `P[i]` at center `i` in the transformed array, we map it back to the original array `nums`:
*   **Original Length:** `len = P[i]`
*   **Original Start Index:** `start = (i - P[i] - 1) / 2`
Using these mapped indices, we evaluate `pref[start + len] - pref[start]` and update our global `maxSum`.

### 💻 Java Implementation

```java
class Solution {
    public long maxPalindromicSubarraySum(int[] nums) {
        int n = nums.length;
        
        // 1. Prefix sum for O(1) subarray sum queries
        long[] pref = new long[n + 1];
        for (int i = 0; i < n; i++) {
            pref[i + 1] = pref[i] + nums[i];
        }

        // 2. Transform array with impossible negative numbers
        int[] t = new int[2 * n + 3];
        t[0] = -2; // Start sentinel
        t[1] = -1; // Separator
        for (int i = 0; i < n; i++) {
            t[2 * i + 2] = nums[i];
            t[2 * i + 3] = -1;
        }
        t[2 * n + 2] = -3; // End sentinel

        int m = t.length;
        int[] p = new int[m];
        int center = 0, right = 0;
        long maxSum = 0;

        // 3. Manacher's Algorithm Core
        for (int i = 1; i < m - 1; i++) {
            int mirror = 2 * center - i;
            
            // Utilize previously computed mirror radius if within the right boundary
            if (right > i) {
                p[i] = Math.min(right - i, p[mirror]);
            }
            
            // Expand palindrome centered at i
            while (t[i + 1 + p[i]] == t[i - 1 - p[i]]) {
                p[i]++;
            }
            
            // Update center and right boundary if we expanded past R
            if (i + p[i] > right) {
                center = i;
                right = i + p[i];
            }

            // 4. Map back to original array and calculate sum
            if (p[i] > 0) {
                int len = p[i]; 
                int start = (i - 1 - p[i]) / 2; // Magic formula for boundary-padded transformation
                
                long currentSum = pref[start + len] - pref[start];
                if (currentSum > maxSum) {
                    maxSum = currentSum;
                }
            }
        }

        return maxSum;
    }
}
```
