You are given an integer array demand, where demand[i] is the amount of fuel required by the ith car.

You are also given an integer array fuel of length 2. There are exactly two fuel dispensers, numbered 0 and 1, where fuel[j] is the initial amount of fuel available in dispenser j.

Cars are allowed to start refueling in increasing index order. Car 0 becomes allowed at time 0, and for each i > 0, car i becomes allowed exactly when car i - 1 starts refueling.

The refueling process follows these rules:

Each dispenser can serve at most one car at a time.
When a car becomes allowed, you must choose a dispenser with at least demand[i] fuel remaining. If both dispensers have enough fuel remaining, you may choose either of them, regardless of when they become free.
The car waits until the chosen dispenser becomes free and starts refueling immediately. It cannot switch dispensers or intentionally wait after the chosen dispenser becomes free.
When a car starts refueling, the remaining fuel in the chosen dispenser decreases by demand[i], and the dispenser remains occupied for demand[i] seconds.
Once started, refueling cannot be interrupted.
If neither dispenser has at least demand[i] fuel remaining when car i becomes allowed, the process terminates and no further cars can be served.
The waiting time of a car is the time between when it becomes allowed to start refueling and when it actually starts.

Return the minimum possible value of the maximum waiting time among all served cars over all assignments that maximize the number of served cars. If no car can be served, return -1.

 

Example 1:

Input: demand = [6,8,4,6,5], fuel = [16,13]

Output: 6

Explanation:

The following assignment serves all five cars:

| Car | Becomes allowed at | Starts refueling at | Dispenser used | Remaining fuel before start<br>(dispenser 0, dispenser 1) | Waiting time |
| :---: | :---: | :---: | :---: | :---: | :---: |
| 0 | 0 | 0 | 0 | (16, 13) | 0 |
| 1 | 0 | 0 | 1 | (10, 13) | 0 |
| 2 | 0 | 6 | 0 | (10, 5) | 6 |
| 3 | 6 | 10 | 0 | (6, 5) | 4 |
| 4 | 10 | 10 | 1 | (0, 5) | 0 |

Thus, all five cars are served, and the maximum waiting time is 6.

To serve all five cars, dispenser 0 must serve the cars with demands 6, 4, and 6, while dispenser 1 must serve the cars with demands 8 and 5. Therefore, car 2 must wait until time 6 for dispenser 0 to become free, so no assignment serving all five cars can have a maximum waiting time less than 6.

Example 2:

Input: demand = [10,15], fuel = [12,17]

Output: 0

Explanation:

At time 0, Car 0 becomes allowed and starts refuelling using dispenser 0.
Car 1 becomes allowed at time 0 (when Car 0 starts) and immediately starts refuelling using dispenser 1.
Both cars start without waiting, so the maximum waiting time is 0.
Example 3:

Input: demand = [10,5], fuel = [8,8]

Output: -1

Explanation:

At time 0, Car 0 becomes allowed. However, neither dispenser has enough fuel to serve it, so the process terminates immediately.
No car is served, so the answer is -1.
 

Constraints:

1 <= demand.length <= 50
1 <= demand[i] <= 20
fuel.length == 2
1 <= fuel[i] <= 50


Thought:

## 💡 Intuition & Approach

At first glance, tracking the absolute time for each car seems to require an infinitely growing state. However, the core breakthrough lies in using **Relative Time Transformation** and **State Compression**. 

Instead of tracking the exact global timeline, we only need to track the *remaining busy time* of each dispenser from the perspective of the current car. Since the maximum demand of any car is `20`, a dispenser's busy time will never exceed `20`. This strictly bounds our state space.

### 1. State Definition
We define a 3D Dynamic Programming array `dp[f1][i][j]`, which stores the **minimum possible maximum waiting time** (the historical worst-case wait) among all processed cars, where:
* `f1`: Remaining fuel in Dispenser 0. *(Note: We don't need to track Dispenser 1's fuel because `f2 = total_fuel - consumed_fuel - f1`)*.
* `i`: Remaining busy time for Dispenser 0 (`0 <= i <= 20`).
* `j`: Remaining busy time for Dispenser 1 (`0 <= j <= 20`).

### 2. The "Relative Time" Transition (The Magic)
When a car arrives, its waiting time `w` is exactly the remaining busy time of the chosen dispenser. 
The most crucial logic is **what happens to the *other* dispenser while the car is waiting**:
* While the car waits `w` seconds for Dispenser A, Dispenser B continues to work for `w` seconds.
* Therefore, Dispenser B's new busy time becomes `max(0, old_busy_time - w)`.

**If we assign the car to Dispenser 0:**
* Wait time: `w = i`
* New historical max wait: `max(w, dp[f1][i][j])` *(Update the worst record for this timeline)*
* Next Dispenser 0 busy time: `demand` *(Starts fueling the current car)*
* Next Dispenser 1 busy time: `max(0, j - i)` *(Works while we waited `i` seconds)*

**If we assign the car to Dispenser 1:**
* Wait time: `w = j`
* New historical max wait: `max(w, dp[f1][i][j])`
* Next Dispenser 0 busy time: `max(0, i - j)`
* Next Dispenser 1 busy time: `demand`

### 3. Min-Max Optimization
For every valid transition, we take the `Math.min()` of the target state and the newly calculated max wait. 
* The **internal `max()`** tracks the worst-case waiting time *within* a specific timeline.
* The **external `min()`** selects the most optimal timeline out of all possible scheduling branches.

### ⏱️ Complexity
* **Time Complexity:** $\mathcal{O}(N \times F \times 21 \times 21)$, where $N$ is the number of cars and $F$ is the initial fuel of Dispenser 0. Since $N \le 50$, $F \le 50$, the maximum operations are roughly $50 \times 51 \times 21 \times 21 \approx 1.1 \times 10^6$, which easily runs in $\sim 10$ ms.
* **Space Complexity:** $\mathcal{O}(F \times 21 \times 21)$ to store the DP states for the current and next iteration, safely within memory limits.

Solution:

```
class Solution {
    public int minMaxWaitingTime(int[] demands, int[] fuel) {
        int[][][] dp = new int[fuel[0] + 1][21][21];
        int currentSum = 0;

        for (int[][] arr2d : dp)
            for (int[] arr1d : arr2d)
                Arrays.fill(arr1d, Integer.MAX_VALUE);

        dp[fuel[0]][0][0] = 0;

        for (int demand : demands) {
            int[][][] nextDp = new int[fuel[0] + 1][21][21];
            boolean canServe = false;

            for (int[][] arr2d : nextDp)
                for (int[] arr1d : arr2d)
                    Arrays.fill(arr1d, Integer.MAX_VALUE);

            for (int f1 = 0; f1 <= fuel[0]; f1++) {
                int f2 = fuel[0] + fuel[1] - f1 - currentSum;
                if (f2 < 0) break;

                for (int i = 0; i <= 20; i++)
                    for (int j = 0; j <= 20; j++) {
                        if(dp[f1][i][j] == Integer.MAX_VALUE) continue;

                        if (demand <= f1) {
                            int w = Math.max(i, dp[f1][i][j]);
                            int nextF1 = f1 - demand;
                            int nextI = demand;
                            int nextJ = Math.max(0, j - i);
                            nextDp[nextF1][nextI][nextJ] = Math.min(nextDp[nextF1][nextI][nextJ], w);
                            canServe = true;
                        }

                        if (demand <= f2) {
                            int w = Math.max(j, dp[f1][i][j]);
                            int nextF1 = f1;
                            int nextI = Math.max(0, i - j);
                            int nextJ = demand;
                            nextDp[nextF1][nextI][nextJ] = Math.min(nextDp[nextF1][nextI][nextJ], w);
                            canServe = true;
                        }
                    }
            }

            if (!canServe) return currentSum == 0 ? -1 : findMinWait(dp);

            currentSum += demand;
            dp = nextDp;
        }

        return findMinWait(dp);
    }

    private int findMinWait(int[][][] dp) {
        int ans = Integer.MAX_VALUE;
        for (int[][] arr2d : dp)
            for (int[] arr1d : arr2d)
                for (int x : arr1d)
                    ans = Math.min(ans, x);

        return ans;
    }
}
```
