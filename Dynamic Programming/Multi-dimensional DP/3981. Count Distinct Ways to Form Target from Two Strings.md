You are given three strings word1, word2, and target.

Your task is to count the number of ways to form target by choosing characters from word1 and word2 under the following conditions:

For each character of target, choose one matching character from either word1 or word2.
The chosen indices from word1 must be strictly increasing.
The chosen indices from word2 must be strictly increasing.
At least one character must be chosen from both word1 and word2.
Two ways are considered different if, for at least one position in target, the chosen character comes from a different string or a different index.

Return the number of ways. Since the answer may be very large, return it modulo 109 + 7.

 

Example 1:

Input: word1 = "abc", word2 = "bac", target = "abc"

Output: 5

Explanation:

There are 5 ways to form target:

word1[0] = 'a', word1[1] = 'b', word2[2] = 'c'
word1[0] = 'a', word2[0] = 'b', word1[2] = 'c'
word1[0] = 'a', word2[0] = 'b', word2[2] = 'c'
word2[1] = 'a', word1[1] = 'b', word1[2] = 'c'
word2[1] = 'a', word1[1] = 'b', word2[2] = 'c'
All ways preserve the increasing index order inside each string and choose at least one character from each string.

Example 2:

Input: word1 = "cd", word2 = "cd", target = "ccd"

Output: 4

Explanation:

There are 4 ways to form target:

word1[0] = 'c', word2[0] = 'c', word1[1] = 'd'
word1[0] = 'c', word2[0] = 'c', word2[1] = 'd'
word2[0] = 'c', word1[0] = 'c', word1[1] = 'd'
word2[0] = 'c', word1[0] = 'c', word2[1] = 'd'
The first two 'c' characters in target must come one from each string. The final 'd' can be chosen from either string.

Example 3:

Input: word1 = "xy", word2 = "xy", target = "xyxy"

Output: 2

Explanation:

There are 2 ways to form target:

word1[0] = 'x', word1[1] = 'y', word2[0] = 'x', word2[1] = 'y'
word2[0] = 'x', word2[1] = 'y', word1[0] = 'x', word1[1] = 'y'
Each "xy" part in target comes entirely from one string.

Example 4:

Input: word1 = "ab", word2 = "cde", target = "ace"

Output: 1

Explanation:

The only way is to choose word1[0] = 'a', word2[0] = 'c', and word2[2] = 'e'. Thus, the answer is 1.

 

Constraints:

1 <= word1.length, word2.length, target.length <= 100
word1, word2, and target consist of lowercase English letters only.


# 🌟 Demystifying the 2D Inclusion-Exclusion DP: The "Prefix Sum" Trap

When solving complex subsequence-matching problems like **LeetCode 3981 (Count Distinct Ways to Form Target from Two Strings)**, utilizing a 2D dynamic programming array is a standard approach. 

However, achieving a true $\mathcal{O}(1)$ state transition inside the loops requires merging 2D prefix sums on the fly. This often leads to a notorious bug: **Exponential Double-Counting**. 

Here is a deep dive into the mathematical mechanics of the $O(K \cdot N_1 \cdot N_2)$ solution, specifically answering the question: *"Why do we need to subtract `dpCur[i-1][j-1]` when a character matches?"*

---

### 🛡️ Phase 1: Spatial Inheritance (The 2D Propagation)

At the beginning of our loop, we execute the standard 2D Inclusion-Exclusion formula:
```java
if (i > 0) dpNxt[i][j] = (dpNxt[i][j] + dpNxt[i - 1][j]) % mod;
if (j > 0) dpNxt[i][j] = (dpNxt[i][j] + dpNxt[i][j - 1]) % mod;
if (i > 0 && j > 0) dpNxt[i][j] = ((dpNxt[i][j] - dpNxt[i - 1][j - 1]) % mod + mod) % mod;
What does this do?This acts as a "wind tunnel" blowing to the bottom-right. It ensures that any valid subsequence scheme discovered at a smaller boundary (like i-1 or j-1) is automatically inherited by the current, larger boundary (i, j).If we don't use word1[i] or word2[j] at all to match the current target character, the number of ways to form the target remains exactly what was calculated previously.🧬 Phase 2: State Mutation (The Birth of New Paths)When a character actually matches (e.g., word1.charAt(i-1) == target.charAt(k)), we must append the successful paths from the previous round (dpCur) into our current round (dpNxt).A naive approach would be to simply add the previous state:Java// ❌ DANGER: This causes Double-Counting!
dpNxt[i][j] = (dpNxt[i][j] + dpCur[i - 1][j]) % mod; 
Why is this wrong?Because dpCur is a Prefix Sum Array. dpCur[i-1][j] represents all valid ways using up to j characters from word2.It contains two distinct groups of paths:Paths that used exactly $j$ characters from word2.Paths that used $\le j-1$ characters from word2 (these are basically dpCur[i-1][j-1]).If we blindly inject the total dpCur[i-1][j] into dpNxt[i][j], we are injecting Group 2 into the coordinate (i, j).However, Group 2 was already injected earlier at coordinate (i, j-1)! Because of the "Spatial Inheritance" (Phase 1), Group 2 has already been automatically carried over into (i, j).By adding it again, we are counting the same paths twice, causing an exponential explosion in our results.🎯 The Fix: Extracting the "Pure Delta"To prevent this overlap, we must strictly enforce a rule: Only inject paths whose "exact birth coordinate" is (i, j).We achieve this by stripping away all historical, smaller-boundary paths from the total prefix sum. Mathematically, this is the discrete derivative (difference) of the prefix sum:Pure Paths ending exactly at j = Total Paths up to j - Total Paths up to j-1Translated to code:Java// ✅ Extract the exact delta to prevent duplicate propagation
dpNxt[i][j] = (dpNxt[i][j] + dpCur[i - 1][j]) % mod;
if (j > 0) {
    dpNxt[i][j] = ((dpNxt[i][j] - dpCur[i - 1][j - 1]) % mod + mod) % mod;
}
💡 SummaryA + B - A∩B (The first 3 lines): Smoothly shifts all historical, non-matching paths to the right and down.dpCur[i-1][j] - dpCur[i-1][j-1]: Extracts the pure, unadulterated "new" paths that absolutely require the $j$-th boundary to exist.By inserting only the pure delta into the grid, we guarantee that as the spatial inheritance pushes these numbers forward, no path is ever counted more than once.


Solution:

```
class Solution {
    public int interleaveCharacters(String word1, String word2, String target) {
        long mod = (long)(1e9 + 7);
        int m = word1.length(), n = word2.length(), l = target.length();
        long[][] dpCur = new long[m + 1][n + 1];

        for (int i = 0; i <= m; i++)
            for (int j = 0; j <= n; j++)
                dpCur[i][j] = 1L;

        for (int k = 0; k < l; k++) {
            long[][] dpNxt = new long[m + 1][n + 1];

            for (int i = 0; i <= m; i++)
                for (int j = 0; j <= n; j++) {
                    if (i > 0) dpNxt[i][j] = (dpNxt[i][j] + dpNxt[i - 1][j]) % mod;
                    if (j > 0) dpNxt[i][j] = (dpNxt[i][j] + dpNxt[i][j - 1]) % mod;
                    if (i > 0 && j > 0) dpNxt[i][j] = ((dpNxt[i][j] - dpNxt[i - 1][j - 1]) % mod + mod) % mod;

                    if (i > 0 && word1.charAt(i - 1) == target.charAt(k)) {
                        dpNxt[i][j] = (dpNxt[i][j] + dpCur[i - 1][j]) % mod;
                        if (j > 0)
                            dpNxt[i][j] = ((dpNxt[i][j] - dpCur[i - 1][j - 1]) % mod + mod) % mod;
                    }
                    if (j > 0 && word2.charAt(j - 1) == target.charAt(k)) {
                        dpNxt[i][j] = (dpNxt[i][j] + dpCur[i][j - 1]) % mod;
                        if (i > 0)
                            dpNxt[i][j] = ((dpNxt[i][j] - dpCur[i - 1][j - 1]) % mod + mod) % mod;
                    }
                }

            dpCur = dpNxt;
        }

        long res = ((dpCur[m][n] - getSingleWay(word1, target, mod) - getSingleWay(word2, target, mod)) % mod + mod) % mod;
        return (int)res;
    }

    private long getSingleWay(String src, String dst, long mod) {
        int m = src.length(), n = dst.length();
        long[] dpCur = new long[m + 1];
        for (int i = 0; i <= m; i++) dpCur[i] = 1L;

        for (int k = 0; k < n; k++) {
            long[] dpNxt = new long[m + 1];
            for (int i = 0; i < m; i++) {
                dpNxt[i + 1] = dpNxt[i];
                if (src.charAt(i) == dst.charAt(k))
                    dpNxt[i + 1] = (dpNxt[i + 1] + dpCur[i]) % mod;
            }

            dpCur = dpNxt;
        }

        return dpCur[m];
    }
}
